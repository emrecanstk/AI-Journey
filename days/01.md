### Start of the day

### 2.1 — Single neuron

Very simple first experiment. Two inputs, two weights, one bias:

```python
x1 = 2
x2 = 3
w1 = 0.5
w2 = 0.8
bias = 0.1
output = (x1 * w1) + (x2 * w2) + bias
```

By hand:

```
2 × 0.5  = 1.0
3 × 0.8  = 2.4
+ bias   = 0.1
           3.5
```

Run printed `3.5` (tiny float noise: `3.5000000000000004`).

What this is: each input is scaled by a **weight**, then **bias** shifts the result. No learning yet. Just the forward formula of one neuron.

### 2.2 — What we did here

Flow:

```
inputs
  ↓
weights
  ↓
weighted sum
  ↓
output
```

Math:

```
z = x1*w1 + x2*w2 + b
```

This is the most basic form of a neuron: a weighted sum plus bias.

### 2.3 — Activation function (ReLU)

A weighted sum can be any real number. Networks usually pass `z` through a non-linear **activation**. We added ReLU:

```python
def relu(x):
    return max(0, x)
```

Then:

```python
z = (x1 * w1) + (x2 * w2) + bias
output = relu(z)
```

With the original bias, `z = 3.5` and `relu(3.5) = 3.5`. Positive numbers pass through.

Then we made `z` negative with `bias = -5`:

```
z = 1.0 + 2.4 + (-5) = -1.6
relu(-1.6) = 0
```

Observation: ReLU **cuts off** negatives. The neuron goes quiet. That is the point of activation: not every weighted sum should flow forward unchanged.

### 2.4 — Write sigmoid yourself

Formula, no lookup:

```
σ(x) = 1 / (1 + e^(-x))
```

```python
def sigmoid(x):
    return 1 / (1 + math.exp(-x))
```

Observed:

| x | sigmoid(x) | Read |
| --- | --- | --- |
| -10 | ≈ 0.000045 | almost 0 |
| 0 | 0.5 | midpoint |
| +10 | ≈ 0.99995 | almost 1 |

Goal today: not to memorize activations. ReLU is a switch (keep or zero). Sigmoid **squishes** any real number into `(0, 1)`.

### Two neurons — one hidden layer

Same inputs `x1=2`, `x2=3` go into **two** neurons. Different weights, different bias, then ReLU.

Neuron 1: `z1 = 3.5` → `h1 = 3.5`  
Neuron 2: `z2 = 2*(-0.3) + 3*0.4 + 0.2 = 0.8` → `h2 = 0.8`

Print:

```
Neuron 1: 3.5
Neuron 2: 0.8
```

Both neurons see the same `x`. They produce different numbers because their weights differ. That is a layer: several views of the same input.

### What are h1 and h2?

Flow for one neuron:

```
x
  ↓
weighted sum
  ↓
activation
  ↓
hidden representation
```

`h1` and `h2` are the input's **representations transformed by the network**.

Yesterday we saw embeddings: a sentence became 384 numbers. Today we saw the smallest version of that idea: two numbers `[h1, h2]` that are no longer raw `x1, x2`. They are `x` after weights, bias, and activation.

### 04 — Loss + learning intuition

The neuron so far only **computed**. Now: how does a network **learn**?

Simple goal: `input = 2`, `target = 10`. The model currently predicts `6`. It is wrong.

**Squared error:**

```python
prediction = 6
target = 10
loss = (prediction - target) ** 2
```

Run printed **16**. `(6 - 10) ** 2 = (-4) ** 2 = 16`. Squaring makes the error positive and larger mistakes grow faster. Loss is a number that says “how wrong”.

Then we changed the **weight**. Tiny model: `prediction = 2 * weight`, still `target = 10`.

| weight | prediction | loss |
| --- | --- | --- |
| 0.5 | 1.0 | 81.0 |
| 1.0 | 2.0 | 64.0 |
| 1.5 | 3.0 | 49.0 |
| 2.0 | 4.0 | 36.0 |
| 2.5 | 5.0 | 25.0 |

As **weight** changes, **prediction** changes, and therefore **loss** changes. Loss is falling toward the target (`prediction` would be 10 when `weight = 5`). We did not take that last step yet. The intuition is enough: learning means moving weights so loss goes down.

### 07 — Self-attention

Most important part of the day: **Attention**. Understand the problem first, not the formula.

**7.1 — The problem**

Sentence: `"The animal didn't cross the street because it was tired."`

What does `it` refer to? A human says `animal`, not `street`. The model must see **relations between tokens**. That is where Attention comes in.

**7.2 — Core idea**

Each token asks: which other tokens matter for me?

For `it`, candidates have different importance: `animal`, `street`, `tired`. Attention is a way to score that.

**7.3 — Q, K, V (do not memorize names)**

Think of it like this:

- **Query** — what am I looking for?
- **Key** — what information do I have?
- **Value** — if you pick me, what do I give you?

`it` is a query looking for an antecedent. `animal` and `street` hold keys. The matching key unlocks that token's value.

**7.4 — Math (do not memorize today)**

```
Attention(Q, K, V) = softmax(Q K^T / √d_k) V
```

Know these three stages:

```
Q × K
  ↓
attention scores
  ↓
softmax
  ↓
weighted values
```

**7.5–7.7 — Mini numerical example**

Tiny 2×2 matrices in `experiments/attention/self_attention.py`. Two “tokens”. `d_k = 2`, so we divide scores by `√2`.

Original Q = K = identity. Token 0 matches token 0; token 1 matches token 1.

| step | result |
| --- | --- |
| scores `Q @ K.T` | `[[1, 0], [0, 1]]` |
| scaled `/ √2` | `[[0.707, 0], [0, 0.707]]` |
| softmax weights | `[[0.67, 0.33], [0.33, 0.67]]` |
| output `weights @ V` | `[[6.70, 6.60], [3.30, 13.40]]` |

Softmax never makes the off-diagonal exactly 0. Token 0 still mostly takes V from token 0 (`10` mixed with a bit of `20`). That mix **is** attention: weighted information transfer.

Stop and break it down:

```
Q × K^T → scores → scale → softmax → weights → × V → output
```

That is the core of self-attention.

**Experiment — change Q**

Tilted Q `[[0.9, 0.1], [0.1, 0.9]]`: weights stay peaked on the diagonal, a bit softer (`0.64 / 0.36`).

Mixed Q `[[0.5, 0.5], [0.5, 0.5]]`: both tokens ask the same thing. Weights become `[[0.5, 0.5], [0.5, 0.5]]`. Output is the average of the two values: `[[5, 10], [5, 10]]`.

Goal: feel mathematically that attention is **weighted information transfer between tokens**. Change Q (what you look for) and the mix of V (what you receive) changes.

### 09 — Transformer block

Now the pieces snap together. A simplified Transformer block:

```
Token IDs
  ↓
Embedding
  ↓
Positional Information
  ↓
Self Attention
  ↓
Residual Connection
  ↓
Layer Normalization
  ↓
Feed Forward Network
  ↓
Residual Connection
  ↓
Layer Normalization
```

That whole stack is one **Transformer block**. An LLM is many of these stacked. Attention alone is not a Transformer.

**9.1 — Why residual connection?**

Input splits: one path through attention (or FFN), one path skips. Then they add:

```
output = input + transformation(input)
```

Demo in `experiments/transformer-block/block.py`: `[1, 2, 3] + [0.5, -0.2, 0.1] = [1.5, 1.8, 3.1]`. The original signal is not erased. This is one of the ideas that makes deep networks trainable.

**9.2 — Feed Forward Network**

Roughly:

```
x → Linear → Activation → Linear → output
```

Tiny run: `x = [1, -2, 0.5]` → after Linear+ReLU `[1, 0, 0.5, 0]` (the -2 died) → second Linear `[1, 0, 0.5]`.

So a Transformer is:

```
Attention
+ Feed Forward
+ Normalization
+ Residual Connections
```

### 10 — LLM next-token logic

Most important link of the day.

Give an LLM: `"The cat sat on the"`

Its job is not “understand the sentence and write an answer”. Its job is: **which token is more likely next?**

Example distribution:

- mat: 0.42
- floor: 0.21
- chair: 0.08
- table: 0.04

Then the new token is appended (`"The cat sat on the mat"`) and the same loop runs again.

```
context
  ↓
Transformer
  ↓
logits
  ↓
probabilities
  ↓
next token
```

**10.1 — Logits**

A logit is the **raw score** for each possible next token. Then:

```
logits → softmax → probabilities
```

**10.2 — Temperature (intuition only)**

Temperature does **not** retrain the model. It only reshapes the distribution at inference.

Same logits in the demo:

| token | T=0.5 | T=1.0 | T=2.0 |
| --- | --- | --- | --- |
| mat | 0.776 | 0.565 | 0.411 |
| floor | 0.191 | 0.281 | 0.290 |
| chair | 0.026 | 0.103 | 0.176 |
| table | 0.006 | 0.051 | 0.124 |

Low T: more deterministic (peak on `mat`). High T: more diverse / random (mass spreads).

**7.5–7.7 — Mini sayısal örnek**

Küçük 2×2 matrisler: `experiments/attention/self_attention.py`. İki “token”. `d_k = 2`, skorları `√2`'ye böleriz.

Orijinal Q = K = birim matris. Token 0 token 0'a, token 1 token 1'e bakar.

| adım | sonuç |
| --- | --- |
| scores `Q @ K.T` | `[[1, 0], [0, 1]]` |
| scaled `/ √2` | `[[0.707, 0], [0, 0.707]]` |
| softmax weights | `[[0.67, 0.33], [0.33, 0.67]]` |
| output `weights @ V` | `[[6.70, 6.60], [3.30, 13.40]]` |

Softmax köşegen dışını tam 0 yapmaz. Token 0 hâlâ çoğunlukla token 0'ın V'sini alır (`10`, biraz `20` karışık). Bu karışım **attention'ın kendisi**: ağırlıklı bilgi aktarımı.

```
Q × K^T → scores → scale → softmax → weights → × V → output
```

İşte self-attention'ın çekirdeği.

Eğik Q `[[0.9, 0.1], [0.1, 0.9]]`: ağırlıklar köşegende kalır, biraz yumuşar (`0.64 / 0.36`).

Karışık Q `[[0.5, 0.5], [0.5, 0.5]]`: iki token aynı şeyi sorar. Weights `[[0.5, 0.5], [0.5, 0.5]]`. Output iki value'nun ortalaması: `[[5, 10], [5, 10]]`.

Amaç: Attention'ın "kelimeler arasında ağırlıklı bilgi aktarımı" yaptığını matematiksel olarak hissetmek. Q (ne arıyorsun) değişince V karışımı (ne alıyorsun) değişir.

### 09 — Transformer block

Şimdi parçalar birleşiyor. Basitleştirilmiş Transformer:

```
Token IDs
  ↓
Embedding
  ↓
Positional Information
  ↓
Self Attention
  ↓
Residual Connection
  ↓
Layer Normalization
  ↓
Feed Forward Network
  ↓
Residual Connection
  ↓
Layer Normalization
```

Bu yapıya **Transformer block** denir. Bir LLM bunların birçoğunun üst üste binmiş halidir. Attention tek başına Transformer değildir.

**9.1 — Neden residual connection?**

Girdi ikiye ayrılır: biri attention (veya FFN) yolundan, biri atlar. Sonra toplanır:

```
output = input + transformation(input)
```

Demoda: `[1, 2, 3] + [0.5, -0.2, 0.1] = [1.5, 1.8, 3.1]`. Orijinal sinyal silinmez. Derin network'lerin eğitilmesini kolaylaştıran fikirlerden biri budur.

**9.2 — Feed Forward Network**

Kabaca:

```
x → Linear → Activation → Linear → output
```

Küçük koşu: `x = [1, -2, 0.5]` → Linear+ReLU `[1, 0, 0.5, 0]` (-2 öldü) → ikinci Linear `[1, 0, 0.5]`.

Yani Transformer:

```
Attention
+ Feed Forward
+ Normalization
+ Residual Connections
```

gibi parçaların birleşimidir.

### 10 — LLM next token mantığı

Günün en önemli bağlantısı.

Bir LLM'e: `"The cat sat on the"`

Model "cümleyi anladı ve cevabı yazdı" diye çalışmaz. Görevi: **bundan sonra hangi token gelme ihtimali daha yüksek?**

Örnek dağılım:

- mat: 0.42
- floor: 0.21
- chair: 0.08
- table: 0.04

Sonra yeni token context'e eklenir (`"The cat sat on the mat"`) ve döngü tekrar çalışır.

```
context
  ↓
Transformer
  ↓
logits
  ↓
probabilities
  ↓
next token
```

**10.1 — Logits**

Logit, her olası sonraki token için üretilen **ham skor**. Sonra:

```
logits → softmax → probabilities
```

**10.2 — Temperature (sadece sezgi)**

Temperature modeli yeniden eğitmez. Sadece inference sırasında seçim dağılımını etkiler.

Aynı logits, demoda:

| token | T=0.5 | T=1.0 | T=2.0 |
| --- | --- | --- | --- |
| mat | 0.776 | 0.565 | 0.411 |
| floor | 0.191 | 0.281 | 0.290 |
| chair | 0.026 | 0.103 | 0.176 |
| table | 0.006 | 0.051 | 0.124 |

Düşük T: daha deterministik (`mat` sivri). Yüksek T: daha çeşitli / rastlantısal (kütle yayılır).
