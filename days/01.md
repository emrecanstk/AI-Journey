### 2.1 — Single neuron

Very simple first experiment. Two inputs, two weights, one bias:

```python
x1 = 2
x2 = 3
w1 = 0.5
w2 = 0.8
bias = 0.1
output = (x1 * w1) + (x2 * w2) + bias
```

By hand:

```
2 × 0.5  = 1.0
3 × 0.8  = 2.4
+ bias   = 0.1
           3.5
```

Run printed `3.5` (tiny float noise: `3.5000000000000004`).

What this is: each input is scaled by a **weight**, then **bias** shifts the result. No learning yet. Just the forward formula of one neuron.

### 2.2 — What we did here

Flow:

```
inputs
  ↓
weights
  ↓
weighted sum
  ↓
output
```

Math:

```
z = x1*w1 + x2*w2 + b
```

This is the most basic form of a neuron: a weighted sum plus bias.

### 2.3 — Activation function (ReLU)

A weighted sum can be any real number. Networks usually pass `z` through a non-linear **activation**. We added ReLU:

```python
def relu(x):
    return max(0, x)
```

Then:

```python
z = (x1 * w1) + (x2 * w2) + bias
output = relu(z)
```

With the original bias, `z = 3.5` and `relu(3.5) = 3.5`. Positive numbers pass through.

Then we made `z` negative with `bias = -5`:

```
z = 1.0 + 2.4 + (-5) = -1.6
relu(-1.6) = 0
```

Observation: ReLU **cuts off** negatives. The neuron goes quiet. That is the point of activation: not every weighted sum should flow forward unchanged.

### 2.4 — Write sigmoid yourself

Formula, no lookup:

```
σ(x) = 1 / (1 + e^(-x))
```

```python
def sigmoid(x):
    return 1 / (1 + math.exp(-x))
```

Observed:

| x | sigmoid(x) | Read |
| --- | --- | --- |
| -10 | ≈ 0.000045 | almost 0 |
| 0 | 0.5 | midpoint |
| +10 | ≈ 0.99995 | almost 1 |

Goal today: not to memorize activations. ReLU is a switch (keep or zero). Sigmoid **squishes** any real number into `(0, 1)`.

### Two neurons — one hidden layer

Same inputs `x1=2`, `x2=3` go into **two** neurons. Different weights, different bias, then ReLU.

Neuron 1: `z1 = 3.5` → `h1 = 3.5`  
Neuron 2: `z2 = 2*(-0.3) + 3*0.4 + 0.2 = 0.8` → `h2 = 0.8`

Print:

```
Neuron 1: 3.5
Neuron 2: 0.8
```

Both neurons see the same `x`. They produce different numbers because their weights differ. That is a layer: several views of the same input.

### What are h1 and h2?

Flow for one neuron:

```
x
  ↓
weighted sum
  ↓
activation
  ↓
hidden representation
```

`h1` and `h2` are the input's **representations transformed by the network**.

Yesterday we saw embeddings: a sentence became 384 numbers. Today we saw the smallest version of that idea: two numbers `[h1, h2]` that are no longer raw `x1, x2`. They are `x` after weights, bias, and activation.

### 04 — Loss + learning intuition

The neuron so far only **computed**. Now: how does a network **learn**?

Simple goal: `input = 2`, `target = 10`. The model currently predicts `6`. It is wrong.

**Squared error:**

```python
prediction = 6
target = 10
loss = (prediction - target) ** 2
```

Run printed **16**. `(6 - 10) ** 2 = (-4) ** 2 = 16`. Squaring makes the error positive and larger mistakes grow faster. Loss is a number that says “how wrong”.

Then we changed the **weight**. Tiny model: `prediction = 2 * weight`, still `target = 10`.

| weight | prediction | loss |
| --- | --- | --- |
| 0.5 | 1.0 | 81.0 |
| 1.0 | 2.0 | 64.0 |
| 1.5 | 3.0 | 49.0 |
| 2.0 | 4.0 | 36.0 |
| 2.5 | 5.0 | 25.0 |

As **weight** changes, **prediction** changes, and therefore **loss** changes. Loss is falling toward the target (`prediction` would be 10 when `weight = 5`). We did not take that last step yet. The intuition is enough: learning means moving weights so loss goes down.

  ↓

Get this loop in your head. In a few days, “How is an LLM trained?” starts from here: same loop, much larger.
