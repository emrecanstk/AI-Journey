### 00 — Bird's-eye map (0–10)

Place this picture in your head. The expectation is **not** to learn the math yet.

```
                 AI MATHEMATICS
           /          |           \
 LINEAR ALGEBRA   PROBABILITY    CALCULUS
 Vector           Probability    Derivative
 Matrix           Softmax        Gradient
 Dot Product                     Loss
           \          |           /
                 NEURAL NETWORK
                      ↓
                  TRANSFORMER
                      ↓
                     LLM
```

How to read it:

- **Linear algebra** is the language of the forward pass: embeddings are vectors, weights are matrices, attention scores are dot products.
- **Probability** is the language of the last step: logits become a distribution, then a next token is sampled.
- **Calculus** is the language of learning: loss, gradient, how weights move.

Those three meet in a **neural network**. A **Transformer** is a neural network with a specific block. An **LLM** is a Transformer used to predict the next token.

### 25–35 — Probability → Softmax

Code: `experiments/math-basics/softmax.py`

The model sees `"The cat is"`. Inside it produces **logits**, not probabilities yet:

- sat → 7.2
- sleeping → 6.4
- running → 3.1
- blue → 1.2

Then:

```
LOGITS → SOFTMAX → PROBABILITIES
```

Softmax: `exp(logit) / sum(exp)`. After the first run, `sat` is the peak and the four numbers sum to **1**. The model now has a distribution for “which token should I pick?”

Then the first logit was raised from 7.2 to **10.0**. `sat` jumped (about 0.69 → 0.97). The others shrank. More confidence in one token **sharpens** the distribution. Same idea as low temperature yesterday, from the other side: a bigger logit gap, a peakier softmax.

### 35–48 — Loss → Gradient → Gradient Descent

A short story is enough.

True answer: 10. Model says: 6. Error exists. `10 - 6 = 4`. **Loss** is how we measure that error (yesterday: squared error → 16).

Critical question: which weight, and by how much? **Gradient** is the arrow: which way to move the weight.

Loop:

```
Loss is high
  ↓
Compute gradient
  ↓
Which direction should I go?
  ↓
Change the weights
  ↓
Is loss falling?
```

That loop is **Gradient Descent**. Tiny run in `experiments/math-basics/gradient_descent.py`: start `weight=2.5` (`pred=5`, `loss=25`), step downhill, prediction climbs toward 10.

### Backpropagation — where it sits

Think of two directions.

**Forward:**

```
INPUT → Layer 1 → Layer 2 → Layer 3 → OUTPUT → LOSS
```

**Then the error walks backward:**

```
LOSS → Layer 3 → Layer 2 → Layer 1
```

Each parameter's share of the error is computed. That reverse walk is **Backpropagation**.

**The distinction to lock today:**

```
Backpropagation  →  computes gradients
Gradient Descent →  updates parameters
```

For now, that is the whole math story: measure wrongness, find the direction, take a step.

```
  → LOGITS

  → LOSS
  → BACKPROPAGATION

  → tekrar
```

20 August is the middle of this pipe (token, embed, transformer, logits, next token). 21 August is the language of the pipe (vector, softmax, loss, gradient) plus the loop that actually learns.

**Inference** (user uses the model):

```
USER INPUT
  → TOKENIZER
  → EMBEDDING
  → TRANSFORMER
  → LOGITS
  → PROBABILITIES
  → NEXT TOKEN
  → OUTPUT
```

Here the model **does not learn weights**. Keep this split sharp. Softmax and temperature live on the inference side. Backprop and gradient descent live only on the training side.

### Backpropagation nerede?

İki yön düşün.

**İleri:**

```
INPUT → Layer 1 → Layer 2 → Layer 3 → OUTPUT → LOSS
```

**Hata geriye yayılır:**

```
LOSS → Layer 3 → Layer 2 → Layer 1
```

Her parametrenin hataya katkısı hesaplanır. Bu: **Backpropagation**.

**Bugün oturtulacak ayrım:**

```
Backpropagation  →  gradientleri hesaplar
Gradient Descent →  parametreleri günceller
```

Şimdilik bütün matematik bundan ibaret: yanlışı ölç, yönü bul, adım at.
